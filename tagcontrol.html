TagControl

A release management application for creating and viewing software releases across four OpenShift clusters.

Overview

Built and deployed TagControl to manage application releases across four OpenShift clusters. The app connected to GitHub through backend endpoints, with ASP.NET Core 10 providing the cache layer and API between the Angular frontend and GitHub API.

Compliance workflow

Integrated the backend with a PCI DSS application to automatically populate release documentation with Git commit and Jira ticket information, reducing manual documentation work.

API contracts

Designed and implemented request and response contracts between application layers using TypeScript and C#.

Technology

Angular • TypeScript • C# • ASP.NET Core 10 • OpenShift • GitHub API
